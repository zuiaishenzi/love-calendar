## 准备构建

需要 DevEco Studio（支持目标系统的 SDK）、HarmonyOS SDK、华为开发者账号；真机调试还需要设备开发者模式和调试签名。编写源码、编译未签名包和模拟器验证不必连接手机。生成绑定设备的调试签名需要目标设备 UDID；首次通过 USB 连接最方便，之后无需一直连接。两台设备都需要被签名 Profile 覆盖，并保持同一个签名身份用于覆盖升级。不要提供账号密码或私钥给聊天。

```powershell
./scripts/build-harmony.ps1 -PrepareOnly
```

在 DevEco 打开脚本输出的准备工程目录，完成 SDK 同步及 Signing Configs 配置。源码来自 `apps/harmony`；在准备工程修改代码后应同步回源码目录，签名配置和证书留在私有本地目录。不要在源码工程里配置个人签名凭据。准备工程保留原快照；源码有修改后需要重新准备。
