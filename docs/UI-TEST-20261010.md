## 本地回退

修改前的文件与 SHA256 校验清单保存在被 Git 忽略的 local-preview-data/ui-rollback-20261010 中。回退前会额外保存当前文件，不改变其他功能文件。

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\local-preview-data\ui-rollback-20261010\restore.ps1
```

若测试版已经部署，回退后用原上传脚本发布恢复的源码，再在服务器运行原 update.sh --retry。回退不影响数据库，不需要重装 App。该备份只在本机，不会上传公开仓库。

系统设置集中提供客户端版本更新；Android App 可在个性设置内预览并选择顶部或底部导航。偏好仅存储在当前设备，网页和 Windows 不显示个性设置。
