# 双端主页面与桌面卡片 Implementation Plan

**Goal:** 桌面留言、个人/安全/系统设置作为主视图；安卓与鸿蒙卡片支持清晰背景、可调遮罩、自动/自选文字颜色、立即刷新及动态反馈。

**Architecture:** 复用现有switchView及原生prompt桥；外观保存在当前设备的账号隔离存储。页面级滚条在内容框外，弹窗/输入框滚条仍属于各自内容区。直接在当前会话逐项实施与验证，不新增依赖、不派发子代理、不发布。

**Tech Stack:** 原生Java/RemoteViews、ArkTS/FormKit、现有HTML/CSS/JavaScript与Node测试。

**Spec:** 本轮用户请求；沿用ANDROID-WIDGET.md账号隔离、目录与发布约束。

## 约束与验证重点

- 显示版本1.9.0；安卓与鸿蒙原生构建10903。旧安装包保留，新产物只进入同级love-app。
- 从菜单、手机返回键和主导航切换均保持单一主页面；嵌套邮箱/注销等确认弹窗仍正常。
- 退出/账号切换清除外观和照片；页面异步加载不能覆盖另一账号或已离开的页面。
- 刷新立即发起网络操作，重复点击合并进行中请求；失败结束动态并保留可重试缓存，不虚报成功。
- 对比色按图像与遮罩后的实际亮度计算，不上传背景图片；自选颜色为合法RGB。
- 保留旧客户端设置入口的兼容行为，新外观控件按版本能力启用。
