# 桌面卡片照片与配色修复 Implementation Plan

**Goal:** Android APK、Harmony HAP照片铺满背景；选择文字颜色后应用到桌面，自动配色按可见照片取样。

**Architecture:** 保留账号隔离和现有原生桥，消除背景边距与重复圆角。网页外观操作自动保存并明确失败状态；两端对居中裁剪后的照片取样。鸿蒙更新按顺序发布，避免旧外观异步覆盖新外观。

**Tech Stack:** Java RemoteViews、ArkTS FormKit、现有网页JS和Node测试。

- [x] 确认安卓1dp外层留白、鸿蒙固定圆角与宿主裁剪叠加；检查现有SDK与官方规范。
- [x] 修改Android布局、双端居中照片取样、外观自动保存、鸿蒙发布顺序与宿主结果确认；新增旧发布/失败重试回归。
