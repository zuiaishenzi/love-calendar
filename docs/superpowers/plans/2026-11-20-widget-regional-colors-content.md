# 卡片分区配色与完整正文 Implementation Plan

**Goal:** Android与Harmony卡片标题、正文、底部分区自动/自选颜色；减少正文过早省略，保持文字可读。

**Architecture:** 扩展现有外观协议，保留旧color作为正文色；新客户端增加titleColor/captionColor，旧配置回退到原统一颜色。自动配色分区取样，从暖色/绿色/中性色中选择满足对比度的颜色。正文使用原生自适应字号、更多行及必要时隐藏装饰说明，超过物理空间仍可点击原入口查看全文。

**Tech Stack:** 网页JS/CSS、Java RemoteViews、ArkTS FormKit、Node和原生模拟器。

- [x] 分区颜色、旧配置兼容、灰阶背景最低4.5:1对比度回归通过；网页与双端协议均支持三个颜色。
- [x] 两端取消正文三行限制；Android 10～16sp原生自适应，Harmony 10～17fp、最多12行；长正文隐藏装饰说明。
- [x] 完整140项测试、六组双端浏览器宽度、严格CSP、Java任务回归通过；Android 16实测95字全文约十行和三色显示；双端构建/签名校验通过。
- [x] 内部构建10905，显示版本1.9.0；旧包保留，新包只放../love-app，未发布。
